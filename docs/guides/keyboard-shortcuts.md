# Keyboard Shortcuts

English | [日本語](keyboard-shortcuts.ja.md)

This page lists the keyboard shortcuts available in GenzoRoom. Some shortcuts depend on the active screen or the current selection.

- On Windows and Linux, use `Ctrl` where macOS uses `⌘` (Command).
- Windows/Linux `Alt` corresponds to macOS `⌥` (Option). macOS displays `Shift` as `⇧`.
- The **Show Keyboard Shortcuts** setting controls whether shortcut hints appear in tooltips and menus. Turning it off does not disable the shortcuts themselves.
- Keys labeled **Numpad** refer to the numeric keypad, not the number keys along the top of the keyboard.
- Shortcuts may be suppressed while typing in input fields or interacting with dialogs and menus, where normal input and navigation take priority.

## Gallery

| Key | Action | Notes |
| --- | --- | --- |
| `R` | Show Recent Photos | |
| `Shift+R` | Reload photos in the current Gallery view | |
| `A` | Show Albums | |
| `C` | Show Calendar | |
| `F` | Show Favorites | |
| `S` | Open Stack Management | |
| `E` | Open Export Management | |
| `D` | Open selected photos in Develop | Returns to the previous Develop session if no photos are selected |
| `V` | Open a preview of the selected photo | Requires a selected photo |
| `Ctrl+A` / `⌘+A` | Select all photos in the Gallery | |
| `X` | Toggle exclusion of selected photos | Available in supported photo lists |
| `Q` | Toggle Export Queue registration for selected photos | |
| `←` / `→` | Move between calendar dates | Calendar view only |
| `Numpad -` / `Numpad +` | Decrease / increase thumbnail size | |

## Full-Screen Photo Preview

| Key | Action | Notes |
| --- | --- | --- |
| `←` / `→` | Go to the previous / next photo | |
| `Space` | Toggle photo selection | Gallery preview only |
| `V` / `Esc` | Close the preview | |
| `Q` | Toggle Export Queue registration | Export Management preview only |
| `W` | Toggle export-ready state | Export Management preview only |

## Develop

| Key | Action | Notes |
| --- | --- | --- |
| `Shift+↑` / `Shift+↓` | Move the slider selection up / down | Changes the selected slider, not its value |
| `Shift+←` / `Shift+→` | Move the selection left / right within the sliders | Selection movement only |
| `↑` / `↓` | Adjust the selected slider by 10 steps | Selected slider only |
| `←` / `→` | Adjust the selected slider by 1 step | Selected slider only |
| `Ctrl+Z` / `⌘+Z` | Undo | |
| `Ctrl+Shift+Z` / `⌘+⇧+Z`, or `Ctrl+Y` / `⌘+Y` | Redo | |
| `Ctrl+C` / `⌘+C` | Copy all adjustment settings | |
| `Ctrl+V` / `⌘+V` | Paste copied adjustment settings | |
| `Ctrl+Alt+C` / `⌘+⌥+C` | Choose adjustments to copy | |
| `Ctrl+Alt+V` / `⌘+⌥+V` | Choose adjustments to paste | |
| `]` | Switch between Immich preview and original photo | Where supported |
| `\` (hold) | Temporarily show the unadjusted photo | |
| `V` | Toggle focused viewer mode | |
| `Shift+Z` | Toggle fit-to-view and the previous zoom/pan position | |
| `Ctrl+Shift+←` / `⌘+⇧+←` | Go to the previous photo in the filmstrip | |
| `Ctrl+Shift+→` / `⌘+⇧+→` | Go to the next photo in the filmstrip | |
| `X` | Toggle exclusion of the filmstrip photo | |
| `Q` | Toggle the photo's Export Queue registration | |
| `G` | Return to Gallery | |
| `Numpad 1` / `2` / `3` | Select the red / green / blue scope channel | |
| `Numpad 0` | Switch the scope to luminance display | |
| `Numpad .` | Switch the scope's vertical-axis scale | |

## Stack Management

| Key | Action | Notes |
| --- | --- | --- |
| `V` | Open a preview of the selected photo | Requires a selected photo |
| `A` | Add selected photos to the selected stack | Requires eligible selected photos |
| `\` | Toggle adjusted thumbnail previews | |
| `Ctrl+Z` / `⌘+Z` | Undo the last edit | Stack Management supports one-step Undo |

For detailed instructions, see the [Stack Management Guide](stacks.md).

## Export Management

| Key | Action | Notes |
| --- | --- | --- |
| `V` | Open a preview of the selected photo | Requires a selected photo |
| `W` | Toggle export-ready state for selected photos | Requires selected photos |
| `Q` | Remove selected photos from the Export Queue | Requires selected photos |
| `Ctrl+Z` / `⌘+Z` | Undo the last Export Management operation | |

The same key may perform different actions depending on the active screen. For example, `V` opens a photo preview in Gallery, closes an open preview, and toggles focused viewer mode in Develop.
