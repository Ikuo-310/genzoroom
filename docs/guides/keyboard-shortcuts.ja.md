# キーボードショートカット

[English](keyboard-shortcuts.md) | 日本語

GenzoRoomのアプリケーションショートカット一覧です。画面や選択状態によって利用できる操作が異なります。

- Windows / Linuxでは `Ctrl`、macOSでは `⌘` が表示される操作は、それぞれCtrlキー / Commandキーを使います。
- Windows / Linuxの `Alt` はmacOSでは `⌥` です。`Shift` はmacOSでは `⇧` と表示されます。
- 設定の「キーボードショートカットの表示」はツールチップやメニューのヒント表示を切り替えます。OFFにしてもショートカットは使用できます。
- `テンキー` と記載したキーは、キーボード上部の数字キーではなくテンキーのキーです。
- 入力欄、ダイアログ、メニューなどでは、入力や画面操作を優先するためショートカットが動作しないことがあります。

## ギャラリー

| キー | 操作 | 備考 |
| --- | --- | --- |
| `R` | 最近の写真を表示 | |
| `Shift+R` | 現在のギャラリーの写真を更新 | |
| `A` | アルバムを表示 | |
| `C` | カレンダーを表示 | |
| `F` | お気に入りを表示 | |
| `S` | STACK管理を表示 | |
| `E` | 出力管理を表示 | |
| `D` | 選択した写真を暗室で開く | 写真未選択時は直前の暗室に戻る |
| `V` | 選択した写真のプレビューを開く | 写真の選択が必要です |
| `Ctrl+A` / `⌘+A` | ギャラリー内の写真をすべて選択 | |
| `X` | 選択した写真の除外を切り替え | 対応する写真一覧で使用できます |
| `Q` | 選択した写真の出力Queue登録を切り替え | |
| `←` / `→` | カレンダーの日付を移動 | カレンダー表示中 |
| `テンキー -` / `テンキー +` | サムネイルを縮小 / 拡大 | |

## 写真フルプレビュー中

| キー | 操作 | 備考 |
| --- | --- | --- |
| `←` / `→` | 前 / 次の写真へ移動 | |
| `Space` | 写真の選択を切り替え | ギャラリーのフルプレビュー中 |
| `V` / `Esc`| プレビューを閉じる | |
| `Q` | 出力Queueへの登録を切り替え | 出力管理のプレビュー中 |
| `W` | 出力待機状態を切り替え | 出力管理のプレビュー中 |

| `Ctrl+V` / `⌘+V` | コピー済み設定をペースト | |

| `Ctrl+Alt+V` / `⌘+⌥+V` | 項目を選んでペースト | |
| `]` | Immichプレビュー・原版写真の切り替え | 対応するプレビューで使用できます |

| `Ctrl+Shift+→` / `⌘+⇧+→` | フィルムストリップの次の写真へ移動 | |

| `Q` | 写真の出力Queueへの登録を切り替え | |
| `G` | ギャラリーに戻る | |
| `テンキー 1` / `2` / `3` | スコープの赤 / 緑 / 青チャンネルを選択 | |
| `テンキー 0` | スコープを輝度表示に切り替え | |
| `テンキー .` | スコープの縦軸スケールを切り替え | |

## STACK管理

| キー | 操作 | 備考 |
| --- | --- | --- |
| `V` | 選択写真のプレビューを開く | 写真の選択が必要です |
| `A` | 選択写真を選択済みSTACKに追加 | 追加可能な写真の選択が必要です |
| `\` | サムネイルの補正済み表示を切り替え | |
| `Ctrl+Z` / `⌘+Z` | 直前の編集を元に戻す | STACK管理の編集は1段階のUndoに対応します |

詳しい操作方法は[STACK管理ガイド](stacks.ja.md)を参照してください。

## 出力管理

| キー | 操作 | 備考 |
| --- | --- | --- |
| `V` | 選択写真のプレビューを開く | 写真の選択が必要です |
| `W` | 選択写真の出力待機状態を切り替え | 写真の選択が必要です |
| `Q` | 選択写真の出力Queue登録を解除 | 写真の選択が必要です |
| `Ctrl+Z` / `⌘+Z` | 出力管理で直前の操作を元に戻す | |

同じキーでも画面によって操作が異なります。たとえば `V` は、ギャラリーでは選択写真のプレビューを開き、プレビュー中は閉じ、暗室ではビューアー集中表示を切り替えます。
